# ระบบประมาณการค่าใช้จ่ายบริการครอบฉนวนไฟฟ้าแรงสูง (Line Guard Estimation)

ระบบเว็บ One-Page สำหรับคำนวณและประมาณการค่าบริการครอบฉนวนป้องกันไฟฟ้าแรงสูง ตามหลักเกณฑ์และอัตราค่าบริการมาตรฐานของการไฟฟ้า

## 📋 คุณสมบัติเด่น (Features)
- 💡 **คำนวณค่าบริการแบบเรียลไทม์ (Interactive Calculator)**:
  - ค่าอุปกรณ์ฉนวนครอบการ์ดไฟฟ้าแรงสูง 100 บาท/ชิ้น/วัน
  - ค่าติดตั้งและรื้อถอน 3,500 บาท/งาน
  - ตัวเลือกสวิตช์คำนวณภาษีมูลค่าเพิ่ม (VAT 7%)
- 📊 **ตารางอ้างอิงราคาตัวอย่าง**: ตารางเปรียบเทียบราคาตามจำนวนวันและจำนวนฉนวน
- 📄 **ดาวน์โหลดเอกสารระเบียบหลักเกณฑ์**: ดาวน์โหลดไฟล์ PDF เอกสารอนุมัติ ผวก. หลักเกณฑ์การคิดค่าบริการฉนวนครอบสายไฟฟ้าแรงสูง
- 📱 **Responsive & Modern Design**: ออกแบบด้วยแกมมูทสีม่วง-ส้มทรงพลัง รองรับมือถือและคอมพิวเตอร์

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **HTML5**: Semantic markup & SEO Ready
- **CSS3**: Vanilla CSS Grid/Flexbox, Dynamic Glassmorphism, Micro-animations, Google Fonts (Kanit & Prompt)
- **JavaScript (ES6+)**: Live calculations, DOM Manipulation, PDF Download integration

## 🚀 การติดตั้งและใช้งาน (Usage)
สามารถเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ได้ทันทีโดยไม่ต้องลงโปรแกรมเพิ่มเติม
